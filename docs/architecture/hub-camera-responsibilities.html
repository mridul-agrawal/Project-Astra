Hub Camera Responsibilities

Project Astra · HubCameraController, 94 lines. What it does each frame, and whether any of it belongs elsewhere.

What it does, once per LateUpdate

The six responsibilities, weighed

The answer: no sub-controllers

These are not several high-level responsibilities. They are five steps of one. Read the diagram left to right: no step means anything without the one before it, and nothing branches. A class that hands this pipeline to three collaborators to produce one Vector3 would be harder to follow than the 94 lines are.

Splitting here would be the same mistake as the dialogue system, pointed the other way — that one built parallel systems where one belonged; this would shatter one coherent job into parts that have no independent meaning.

Two things do belong elsewhere, and neither is a sub-controller. One is a fact that lives with its owner; one is arithmetic that wants a test. Both make the controller smaller, not more distributed.

What I would actually change

  1. Move viewport measurement to MapCamera. It sets refResolutionX, refResolutionY and assetsPPU, so it should answer ViewSizeTiles and PixelsPerUnit. Both cameras then ask the same object instead of each re-deriving it, which removes the only duplicated code between them and deletes the hub controller's three fallback constants and its Awake.
  2. Extract the containment arithmetic as a pure static — the shape the hub already uses for EdgeIndicatorSolver, CardinalRouteFollower and DepartureGate. It buys tests for the room-smaller-than-view case, which has none today while CameraController has a test fixture.
  3. Fix the focus asymmetry in GurukulEventRunner, not here. An event that calls FocusCamera retargets the camera and nothing restores it, so the player walks off screen after the event ends. The runner should remember the target and put it back when the sequence finishes, exactly as it already returns the game state to HubExploration.

After 1 and 2 the controller is roughly 55 lines and does exactly what its name says.
