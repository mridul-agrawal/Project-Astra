One cost the plan never priced. Five editor tools authored the old format, so their conversation-seeding is gone: GurukulPlaceholderDialogue is deleted, the greybox and Hub-1 builders no longer seed conversations, and GurukulProblems no longer validates them. Re-running a builder produces a hub with no conversations. Nothing is broken today — the migrated scripts exist — but seeding in the new format is undone work.
