Phase 0 — Boot (BootScene) · persistent singletons, alive all session
  • GameStateManager CORE
    Top-level state machine; validates every transition.
    uses: GameState, GameStateTransitionTable, GameStateEventChannel
  • SceneLoader CORE
    Maps each GameState to a scene, loads through a fade; instantiates the fader prefab.
  • ScreenFader CORE
    Full-screen fade for every scene swap (SceneLoader-owned, prefab-instantiated).
    uses: SceneFadeSettings
  • GameFlow CORE
    Campaign director (Begin / NotifyCutsceneFinished / NotifyBattleFinished); holds Opening → Map1 → Ending.
    uses: CutsceneId, MapId, CutsceneCatalog, MapCatalog, MapData, DialogueScript
  • InputManager CORE
    Raw input → logical actions, state-gated, DAS.
    uses: InputContext, DelayedAutoShift
  • AudioManager CORE
    Music / SFX / mixer buses.
    uses: SoundId, AudioLibrary, SoundSO, AudioBus
  • DialogueService CORE
    Shared dialogue runner/queue; owns the persistent dialogue view.
    uses: DialogueRunner, IDialogueView/DialogueView, DialogueScript/Segment/Line/Node, DialogueSpeaker/Registry, DialogueSettings, DialogueExpression, PortraitPosition/Facing
  • OverlayManager CORE
    On state change, instantiates Resources/Overlays/{State} prefabs.
    uses: GameStateEventChannel

Shared event-channel SOs created at boot, used throughout: GameStateEventChannel, TurnEventChannel, UnitDeathEventChannel, BattleDialogueEventChannel.

Phase 1 — Splash (Splash scene)
  • SplashScreenController CORE
    Plays the splash video, then → TitleScreen.
Phase 2 — Title (TitleScreen scene)
  • TitleScreenUI CORE
    Title music; on Confirm calls GameFlow.Begin() (→ opening cutscene).
Phase 3 — Opening cutscene (Cutscene scene)
  • CutsceneUI (opening) CORE
    Asks GameFlow for the current script (OPENING_CH01), plays it via DialogueService, reports back when done.
Phase 4 — Map 1 load & spawn (BattleMap scene init)
  • MapBootstrapper CORE
    Orchestrates map setup on scene load.
  • MapRenderer CORE
    Paints MapData onto tilemap layers; terrain queries.
    uses: MapData/MapCatalog/MapId, TilesetDefinition, TerrainType, MapLayer, SyncedAnimatedTile, TerrainBackgroundDatabase
  • PathfindingService + Pathfinder CORE
    Reachability / attack-range graph (Dijkstra + Manhattan).
    uses: TerrainStatTable, TerrainType, MovementType
  • UnitSpawner CORE
    Spawns units from data; creates TestUnit + UnitInventory.
    uses: UnitDefinition/ClassDefinition/UnitDatabase, UnitInstance, UnitRegistry, InventoryLoadout/Item/WeaponData, StatArray, Faction, ClassType, MovementType, weapon enums, PanchaBhuta, Personality
  • CameraController + MapCamera CORE
    Deadzone camera tracking / framing.
  • TurnManager CORE
    Battle orchestrator; runs the prologue, then the phase loop.
    uses: BattlePhaseManager, BattlePhase, TurnEventChannel, UnitRegistry, IBattlePrologue, IScriptedEnemyPhase
Phase 5 — Beat 0 prologue (before turn 1)
  • Map1RaidPrologue (IBattlePrologue) CORE
    The scripted on-map raid cinematic.
    uses: WorldMarker, HitFlashEffect, SpriteFader, CameraController, GridCursor, DialogueService.PlayRoutine (MAP1_PROLOGUE_ARANYA)
Phase 6 — Player / turn loop (interactive core)

Phase 7 — Enemy phase / scripted beats — driven by TurnManager → Map1BattleDirector.TryBuildPhaseScript (no new scripts; determinism via ScriptedCombatRng, deaths via UnitDeathHook → UnitDeathEventChannel)
Phase 8 — Victory & post-victory wrap
  • ExpGranter CORE

  • ExpGainOverlayUI + LevelUpScreenUI CORE

  • BattleVictoryWatcher CORE

  • CommitmentTracker + DeterministicCommitmentEvaluator CORE

  • ChapterClearUI CORE
